# Agentic-Drive: AI-Based Robot Car

An AI-powered autonomous robot car capable of perceiving its environment, making intelligent decisions, and navigating dynamically without human intervention. This project integrates computer vision, sensor fusion, and real-time control algorithms within a robotics framework.

## Project Overview

This project aims to develop a flexible, extensible platform for experimentation and real-world applications in robotics and AI. Inspired by modular robotics platforms such as the Hiwonder Rosorin Pro AI Robot Car Kit and the Hiwonder Vision Raspberry Pi Mecanum Robot Car, Agentic-Drive focuses on advancing autonomy capabilities through a modular AI framework.

## Core Objectives

- **Autonomous Navigation**: Enable the robot to move safely in structured and unstructured environments using AI-based perception and planning
- **Computer Vision Integration**: Implement vision-based capabilities including:
  - Object detection and tracking
  - Lane or path recognition
  - Obstacle avoidance
- **Intelligent Decision-Making**: Develop algorithms that interpret sensor data, adapt to dynamic environments, and execute real-time decisions
- **Modular AI Framework**: Design a system architecture supporting:
  - Easy integration of new AI models
  - ROS 2-based communication and scalability
  - Simulation-to-real transfer (e.g., Isaac Sim, Gazebo)

## Project Scope

### Functional Scope
- Real-time perception using camera and onboard sensors
- Autonomous driving in indoor and semi-structured environments
- Basic interaction with dynamic obstacles (humans, objects)
- Teleoperation fallback for testing and safety

### Non-Functional Scope
- Scalability for future research (swarm robotics, delivery systems)
- Hardware-agnostic design (flexible BOM)
- Emphasis on software architecture and AI capabilities

## Expected Outcomes

- A working prototype of an AI-driven robot car capable of autonomous navigation
- A reusable robotics software stack based on ROS 2
- Demonstrations of:
  - Vision-based navigation
  - Real-time obstacle avoidance
  - Adaptive behavior in changing environments
- A foundation for extending into autonomous delivery systems, multi-agent robotic coordination, and smart mobility research

## Potential Applications

- **Autonomous Delivery Systems**: Ground-based last-mile delivery solutions
- **Smart Surveillance & Inspection**: Automated patrol in warehouses or campuses
- **Educational & Research Platform**: AI, robotics, and computer vision experimentation
- **Warehouse Automation**: Inventory transport and tracking in indoor environments

## Strategic Vision

This project serves as a stepping stone toward more advanced autonomous systems, including aerial drones and multi-robot coordination platforms. By focusing on AI-driven perception and decision-making in a ground vehicle, the system will provide a controlled environment to validate algorithms before deploying them in more complex aerial or swarm-based systems.
